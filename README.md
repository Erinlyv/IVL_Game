## 关于

IVL 模拟器是一款以《第五人格》职业电竞为背景的**生涯模拟**网页游戏。玩家从角色创建开始,经历训练、比赛、剧情抉择,体验一名职业选手的成长生涯。当前为可玩垂直切片(vertical slice),纯前端实现,运行时零依赖、即开即玩。

## 🏅 v7.0 运动会支线

v7.0 将 `feedbacks/亚运feedbacks/yyh1.1.md` 和 `运动会支线-demo-v1.1` 合入原有生涯。原支线 demo 和旧版本保持独立。

### 运动会入口

新生涯一次性判定 70% 触发概率,再抽取通知赛年:第 1—4 年各 10%,第 5—7 年各 20%。通知在对应秋季赛结束后出现。拒绝报名、资格筛选失败或选拔落选会返回正常深渊前训练,不再触发。

入选后完成真实的俱乐部深渊赛程,再进入运动会预选赛。运动会在年度结算和最终退役判定之前完成,因此第 7 年入选也能完整参赛。原生涯按“夏→秋→深渊”排列,通知时当年夏季赛已结束;征召缺席对应通知后的下一次夏季赛,只播报俱乐部成绩,不追溯修改已经取得的冠军,第 7 年不额外开启第 8 联赛年。

### 已合入内容

- 25 人候选名单、五轮轮换试训、5 名求生者和 2 名监管者选拔;候选人显示位置与序号。
- 17 支国家和地区代表队。JP 为 75—85,KOR/TPE/HK/THA 为 55—70,其他队伍为 40—55,整届基础实力固定。
- 预选赛 35 场;JP 和 1 支最佳队伍直通八强;正赛小组赛 12 场、各组前三出线;单败八强与半决赛 BO3、决赛沿用原版 D120 流程。
- 比赛由真实属性与临场发挥计算,正式页面没有演示预览、预设路线或预设奖牌。
- 集训共 5 次,不消耗体力,玩家基础成长翻倍,其他国家队成员获得未翻倍基础成长;战术复盘最终 +5/+5,保留既有属性硬上限。
- 金银铜牌与固定人气奖励、奖牌成就和“传奇之上”;不增加联赛冠军、FMVP 或现金,国家队训练不提升未入选俱乐部队友。
- 运动会逐节点保存,试训结果、比赛投点、训练次数、已领取奖励和决赛重放进度均持久化。现有单槽存档键兼容保留,旧档首次载入补齐支线状态。
- 国家队征召导致的俱乐部夏季赛结果在运动会支线结束后再播报;支线结束页已精简为结果、奖牌和人气奖励摘要。
- 集训名单中的 NPC 选手支持点击姓名旁的铅笔按钮自定义选手 ID;系统拒绝空 ID、重复 ID 以及与玩家 ID 相同的输入,并随支线存档保存。
- 生涯按阶段保存进度;运动会结束或出局后回到对应主线节点,不重打已经完成的深渊。

## ✨ 特性

- **角色生成(chargen)**:开局自定义选手档案,选择阵营 / 定位(求生 牵制·救人·ob·辅助 / 监管 追击·控场·守椅)与常用角色
- **生涯事件流**:7 赛年的训练 / 比赛 / 转会 / 突发事件(宠物·版本变更·队内训练等)驱动的状态机玩法
- **深渊黑马模式**:解锁后可从民间队深渊出道,招募队友、喊话、签约职业队并触发专属剧情线
- **赛事系统**:常规赛 / 季后赛 / IVS / 深渊,含 KO 晋级图与**冠亚决赛特殊玩法**(D120 掷骰、按定位分支)
- **运动会支线**:国家队选拔、预选赛、正赛、集训、淘汰赛与奖牌结局,支持逐节点存档恢复
- **结局与成就**:分级成就(白金 / 黄金 / 白银 / 青铜)、可截图分享的生涯战报卡、本地存档续局
- **HUD 数值面板 + 事件流水**:实时反馈成长与抉择结果
- **纯静态前端**:原生 HTML / CSS / JavaScript,无构建步骤、无运行时依赖

## 💻 本地运行

任意静态服务器即可:

```bash

cd IVL_Game
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## ✅ 本地测试

```bash
npm ci
npm test

# 可选:浏览器集成测试,需本机已有 Playwright Chromium;不作为 CI 门禁
npm run test:sports:browser

# 可选:攻略/策略实测,耗时随样本数增加;不作为 CI 门禁
npm run test:strategy -- 5
```

`npm test` 会依次执行语法检查、冒烟、UI、KO/后悔药、冠亚决赛和运动会规则测试。运动会规则测试覆盖 80 个随机种子、名额、赛果与国家队数据隔离、存档往返、训练次数和奖牌重复领取。

浏览器测试使用测试专属构造存档进入真实主线入口,验证试训、集训、淘汰赛投点和决赛中途刷新、领奖恢复、返回主线,以及拒绝报名、资格失败、预选赛出局和 375px 页面。测试快捷参数不出现在正常游戏界面;截图保存在 `/tmp/ivl70-*.png`。
