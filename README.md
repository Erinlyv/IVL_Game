# IVL 模拟器 v7.0

直接用浏览器打开本目录 `index.html`，无需构建。游戏内启动页、网页标题和生涯战报版本均为7.0。

本版将 `feedbacks/亚运feedbacks/yyh1.1.md` 和 `运动会支线-demo-v1.1` 合入原有生涯。原支线demo和旧版本保持独立。

## 运动会入口

新生涯一次性判定70%触发概率，再抽取通知赛年：第1—4年各10%，第5—7年各20%。通知在对应秋季赛结束后出现。拒绝报名、资格筛选失败或选拔落选会返回正常深渊前训练，不再触发。

入选后完成真实的俱乐部深渊赛程，再进入运动会预选赛。运动会在年度结算和最终退役判定之前完成，因此第7年入选也能完整参赛。原生涯按“夏→秋→深渊”排列，通知时当年夏季赛已结束；征召缺席对应通知后的下一次夏季赛，只播报俱乐部成绩，不追溯修改已经取得的冠军，第7年不额外开启第8联赛年。

## 已合入内容

- 25人候选名单、五轮轮换试训、5名求生者和2名监管者选拔；候选人显示位置与序号。
- 17支国家和地区代表队。JP为75—85，KOR/TPE/HK/THA为55—70，其他队伍为40—55，整届基础实力固定。
- 预选赛35场；JP和1支最佳队伍直通八强；正赛小组赛12场、各组前三出线；单败八强与半决赛BO3、决赛沿用原版D120流程。
- 比赛由真实属性与临场发挥计算，正式页面没有演示预览、预设路线或预设奖牌。
- 集训共5次，不消耗体力，玩家基础成长翻倍，其他国家队成员获得未翻倍基础成长；战术复盘最终+5／+5，保留既有属性硬上限。
- 金银铜牌与固定人气奖励、奖牌成就和“传奇之上”；不增加联赛冠军、FMVP或现金，国家队训练不提升未入选俱乐部队友。
- 运动会逐节点保存，试训结果、比赛投点、训练次数、已领取奖励和决赛重放进度均持久化。现有单槽存档键兼容保留，旧档首次载入补齐支线状态。
- 国家队征召导致的俱乐部夏季赛结果在运动会支线结束后再播报；支线结束页已精简为结果、奖牌和人气奖励摘要。
- 集训名单中的 NPC 选手支持点击姓名旁的铅笔按钮自定义选手 ID；系统拒绝空 ID、重复 ID 以及与玩家 ID 相同的输入，并随支线存档保存。
- 生涯按阶段保存进度；运动会结束或出局后回到对应主线节点，不重打已经完成的深渊。

## 文件

- `sports.js`：国家队选拔、真实赛程、支线界面和主线适配。
- `sports-copy.js`：沿用v1.1剧情文案。
- `sports-finals.js`：沿用独立demo的决赛投骰与种子恢复，传入当前赛年和国家队属性。
- `sports.css`：只在运动会期间生效的界面补充样式。
- `game.js`、`engine.js`、`index.html`：主线入口、存档节点、成就结局和资源加载。

## 验证

在项目根目录执行：

```sh
node demo汇总/demo-v7.0/_sportstest.cjs
node demo汇总/demo-v7.0/_sports-browser.cjs
node demo汇总/demo-v7.0/_smoketest.js 100
node demo汇总/demo-v7.0/_gftest.js
node demo汇总/demo-v7.0/_kotest.js
node demo汇总/demo-v7.0/_uitest.js 1
```

运动会规则测试覆盖80个随机种子、名额、赛果与国家队数据隔离、存档往返、训练次数和奖牌重复领取。浏览器测试使用测试专属构造存档进入真实主线入口，验证试训、集训、淘汰赛投点和决赛中途刷新、领奖恢复、返回主线，以及拒绝报名、资格失败、预选赛出局和375px页面。测试快捷参数不出现在正常游戏界面。

`_sports-browser.cjs` 需要本机已有Playwright Chromium；截图保存在 `/tmp/ivl70-*.png`。
